MSc Cybersecurity student at Politecnico di Torino (BSc Computer Science, University of Parma).

**Interests:** security · backend & distributed systems · low-level / embedded

## Selected projects

**[SAGA-Pattern-Exam](https://github.com/GalloFrancesco04/SAGA-Pattern-Exam)**: .NET microservices
implementing the SAGA pattern with Kafka, transactional outbox and compensating transactions.
One-command setup with Docker Compose; CI publishes images to GHCR and a shared NuGet package.

**[Telemetry](https://github.com/GalloFrancesco04/Telemetry-releases)**: lap telemetry app for sim
racing (Assetto Corsa, iRacing) on Windows, with self-updating releases and checksums.

**[Party View](https://github.com/GalloFrancesco04/partyview)** and
**[Token Distance Display](https://github.com/GalloFrancesco04/token-distance-display)**: Foundry VTT
modules I built for my own D&D table: party overview panel and 3D token distance measurement.

**[chessGame](https://github.com/GalloFrancesco04/chessGame)**: chess in C++17 with SFML,
with full move validation, check and checkmate.
